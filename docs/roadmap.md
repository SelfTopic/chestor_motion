## Цель

Видеоредактор для Linux, в котором удобно, как в CapCut на телефоне, и который не тормозит
на слабом ноутбуке. Главное — шортсы для YouTube (9:16) и записи экрана, до 1080p.

Ориентир по функциям — базовый CapCut. Ориентир по железу — Radeon 610M и 7 ГБ памяти:
если плавно работает здесь, будет работать везде.

## Принципы

- **Отзывчивость важнее возможностей.** Каждый этап заканчивается замером на настоящем
  видео: воспроизведение 30 fps, картинка следует за ползунком, интерфейс не замирает.
- **Монтаж по прокси, экспорт из оригиналов.**
- **Всё тяжёлое — не в GUI-потоке.**
- **Управление как в CapCut:** минимум кнопок, всё делается прямо на таймлайне и на превью,
  у частых действий есть горячие клавиши.

## Этапы

### 0. Прототип превью — готово

- [x] Окно на QML, тёмная тема, импорт перетаскиванием и через Ctrl+O
- [x] Плеер на MLT со звуком, пауза, перемотка, шаг по кадрам
- [x] Прокси в фоне: постоянные 30 fps, каждый кадр ключевой, кодирует видеокарта
- [x] Плавная перемотка ползунком в обе стороны на любой скорости

### 1. Таймлайн: одна дорожка

Первый этап, после которого программой уже можно пользоваться: порезать запись и склеить
нужное.

- [x] Модель проекта в Python: клипы на дорожке, сборка из неё MLT-плейлиста
- [x] Таймлайн в QML: клипы с миниатюрами кадров, плейхед, масштаб колесом
- [x] Резать в позиции плейхеда, удалять, менять клипы местами перетаскиванием
- [x] Подрезать клип за края
- [x] Основная дорожка «на магните», как в CapCut: без дыр между клипами
- [x] Отмена и повтор (Ctrl+Z / Ctrl+Shift+Z)
- [x] Сохранение и открытие проекта, автосохранение в черновики
- [ ] Звуковая дорожка клипа на таймлайне (форма волны)

### 2. Экспорт

Сразу после таймлайна: без экспорта результат не забрать.

- [ ] Рендер отдельным процессом (`melt`) из оригиналов, интерфейс не замирает
- [ ] Кодирование H.264 на видеокарте (VA-API), запасной вариант — процессор
- [ ] Пресеты: Shorts 1080×1920, YouTube 1920×1080; 30 и 60 fps
- [ ] Прогресс и отмена

### 3. Холст и текст

- [ ] Соотношение сторон проекта: 9:16, 16:9, 1:1
- [ ] Положение клипа на холсте: вписать, заполнить, двигать и масштабировать прямо на превью
- [ ] Текст: шрифт, цвет, обводка, фон; перетаскивание и масштаб на превью
- [ ] Дорожки для текста и наложений над основной

### 4. Звук и музыка

- [ ] Отдельные звуковые дорожки: музыка, озвучка
- [ ] Громкость клипа, плавное появление и затухание
- [ ] Отключить звук клипа, отделить звук от видео

### 5. Скорость и переходы

- [ ] Скорость клипа (0.25×–4×)
- [ ] Переходы между клипами: наплыв, затемнение
- [ ] Стоп-кадр

### 6. Автосубтитры

Главная фишка CapCut для шортсов.

- [ ] Распознавание речи faster-whisper в фоне, по словам с таймингами
- [ ] Субтитры дорожкой текста, правка текста и таймингов
- [ ] Стили субтитров: подсветка текущего слова, обводка, позиция

### Потом

- Ключевые кадры: зум и сдвиг по времени
- Фильтры и цветокоррекция (возможно, на видеокарте через movit)
- Стикеры и анимации текста
- Звук при перемотке — короткими кусками, без петель
- Шаблоны и сохранённые стили текста

## Технический долг и инфраструктура

- [ ] Превью копирует кадр в RGBA на процессоре. Отдавать YUV и переводить в RGB на
      видеокарте — меньше работы на кадр.
- [ ] CI на GitHub Actions: ruff, pyright, тесты. Нужен MLT с Python-привязками в образе.
- [ ] Прокси для фото (сейчас только видео)
- [ ] Очистка старых прокси в кэше
- [ ] Сборка для установки: пакет в AUR, потом AppImage или Flatpak

## Открытые вопросы

- **60 fps:** превью и прокси сейчас на 30. Нужно ли превью в 60 для записей игр?
- **Прокси для длинных записей:** около 1 ГБ на 10 минут. Если станет много — уменьшать
  разрешение прокси или чистить кэш.
